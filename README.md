# AudioTagger
**AudioTagger** - приложение для управления локальной библиотекой аудиофайлов и редактирования их метаданных (тегов). Проект разработан на языке Python с использованием фреймворка PyQt6.

## Техническое задание и функционал

**Цель проекта:** Создать утилиту для редактирования тегов аудиофайлов различных форматов.

**Реализованный функционал:**
- [x] **Поддержка форматов:** Чтение и запись ID3/Vorbis тегов для `.mp3` и `.flac` файлов.
- [x] **Работа с БД:** Интегрирована локальная база данных SQLite для кэширования библиотеки треков и ведения справочника исполнителей.
- [x] **Мультимедиа:** Встроенный аудиоплеер и поддержка извлечения/записи обложек альбомов прямо в аудиофайл.
- [x] **Горячие клавиши:** Удаление трека из библиотеки по нажатию `Delete`.
- [x] **Интерфейс:** Две формы, спроектированные в `QtDesigner`, использование стандартных окон, контекстное меню по правому клику мыши.

## Архитектура

Проект разделен на слои в соответствии с паттерном **MVC**. 
- **`model/`** — `database.py` (SQLite), `audio_tags.py`.
- **`view/`** — `main_window.py` (Главное окно), `artist_dialog.py` (Управление исполнителями).
- **`controller/`** — `app_controller.py` (Связующая логика).

## Инструкция по установке и запуску

Чтобы запустить проект выполните следующие шаги:

1. Склонируйте репозиторий.
2. Рекомендуется создать виртуальное окружение:
   ```bash
   python -m venv venv
   venv\Scripts\activate
   ```
3. Установите необходимые зависимости из файла `requirements.txt`:
   ```bash
   pip install -r requirements.txt
   ```
4. Запустите главный файл проекта:
   ```bash
   python main.py
   ```

## Руководство пользователя

1. **Сканирование папки:** Нажмите кнопку `Открыть папку` и выберите директорию с вашей музыкой. Программа очистит текущий кэш и загрузит найденные треки в таблицу.
2. **Воспроизведение:** Дважды кликните по любому треку в таблице левой кнопкой мыши (или выделите его и нажмите `▶`), чтобы запустить встроенный плеер.
3. **Редактирование тегов:** 
   - Выделите трек одним кликом.
   - В правой панели измените название, альбом, год или выберите исполнителя из базы.
   - Для изменения обложки, дважды кликните по текущей картинке и выберите файл `.jpg` или `.png`.
   - Нажмите `Сохранить изменения`.
4. **Управление базой исполнителей:** Нажмите кнопку `Исполнители`. В открывшемся окне можно добавлять, переименовывать и удалять исполнителей. Изменения автоматически отразятся во всех связанных треках.
5. **Удаление:** Для удаления трека из библиотеки выделите его и нажмите клавишу `Delete` на клавиатуре или кликните по треку ПКМ и выберите соответствующий пункт контекстного меню.
